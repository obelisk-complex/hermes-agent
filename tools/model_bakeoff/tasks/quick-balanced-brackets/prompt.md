Implement `is_balanced(s: str) -> bool` in `solution.py`.

Return `True` if and only if the bracket characters `()`, `[]`, and `{}` in the
string are balanced and properly nested. Any non-bracket characters are ignored.
The empty string is balanced.

Examples: `"([{}])"` is balanced, `"([)]"` is not, `"a(b)c[d]"` is balanced.

Put your solution in `solution.py` as a function named `is_balanced`.
