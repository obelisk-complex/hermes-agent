Implement `encode(s: str) -> str` in `solution.py`.

Run-length encode the string: each maximal run of a repeated character becomes
that character followed by the length of the run. For example `"aaabb"` becomes
`"a3b2"`, and `"abc"` becomes `"a1b1c1"`. The empty string encodes to `""`.

Return only the encoded string. Put your solution in `solution.py` as a function
named `encode`.
