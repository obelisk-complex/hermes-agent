Implement `evaluate(expr: str) -> int` in `solution.py`.

Integer arithmetic with `+ - * /`, parentheses, and unary minus. Standard precedence,
left-associative. Division `/` TRUNCATES TOWARD ZERO: `-7/2 == -3` (not floor `-4`).
Whitespace is ignored.

On any malformed expression (empty, unbalanced parentheses, a bad token, or division by
zero) raise `ValueError`.
