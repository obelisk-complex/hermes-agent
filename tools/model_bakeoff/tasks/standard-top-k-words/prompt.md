Implement `top_k(text: str, k: int) -> list[str]` in `solution.py`.

Return the `k` most frequent words in `text`. Words are lowercased and split on
whitespace. Order the result by descending frequency; break ties alphabetically
(ascending). If `k` exceeds the number of distinct words, return them all. The
empty string returns an empty list.

Example: `top_k("a a b b b c", 2)` returns `["b", "a"]`.

Put your solution in `solution.py` as a function named `top_k`.
