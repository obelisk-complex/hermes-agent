Implement `to_base(n: int, b: int) -> str` in `solution.py`.

Return the base-`b` representation of a non-negative integer `n` as a lowercase
string, using digits `0-9` then `a-f` for values 10 to 15. `b` must satisfy
`2 <= b <= 16`; raise `ValueError` for any `b` outside that range. `to_base(0, b)`
is `"0"` for every valid `b`.
