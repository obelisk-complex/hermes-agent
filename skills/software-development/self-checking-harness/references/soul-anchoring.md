# SOUL.md Anchoring

SOUL.md is injected into every Hermes session regardless of cwd or reset. It anchors the self-checking-harness protocol as advisory Layer 1.

The relevant sections:

```markdown
## Self-checking harness
**Pre-flight:** load the `self-checking-harness` skill (5-gate protocol) before each substantive task...
**Post-action:** actual state matches config? previously-working still works? new errors? docs updated? temps cleaned?
**Plugin enforcement:** The `self-check-enforcer` plugin mechanically blocks ALL CLEAR claims...
```

SOUL.md is the identity prompt — it establishes expectations but relies on Layer 2 (skill protocol) and Layer 3 (plugin enforcement) for mechanical compliance.
